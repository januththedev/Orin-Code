# Archived: 2026-08-23 Orin Cloud integration plan

This historical plan described the retired Firebase/Clerk token exchange. It
is intentionally not an implementation guide. The current desktop contract is
[`docs/BACKEND-CONTRACT.md`](../../BACKEND-CONTRACT.md), and the Rust bridge
uses Core password compatibility plus PKCE device authentication.

Do not restore the old provider keys, Identity Toolkit calls, or token shapes
from this archive.
